PORTOFOLIO RANDHAN HIDAYAT
==========================

ISI FOLDER
- index.html : struktur dan isi website
- style.css  : desain dan tampilan responsif
- script.js  : interaksi menu dan tahun otomatis

CARA MEMBUKA DI KOMPUTER
1. Ekstrak file ZIP.
2. Buka folder Portfolio_Randhan.
3. Klik dua kali index.html, atau buka melalui browser.
4. Untuk mengedit kode, buka folder ini di Visual Studio Code.

SEBELUM DIKUMPULKAN
1. Ganti emailkamu@example.com di index.html dengan alamat email aktif milikmu.
2. Periksa kembali profil, keahlian, pengalaman, dan proyek.
3. Bagian proyek saat ini berisi contoh/konsep. Ganti dengan proyek yang benar-benar pernah kamu buat atau ubah keterangannya menjadi latihan/contoh sesuai kondisi sebenarnya.
4. Pastikan seluruh file (index.html, style.css, script.js) tetap berada dalam satu folder.

CARA HOSTING GRATIS DENGAN NETLIFY
1. Buka https://app.netlify.com/drop
2. Login atau daftar akun Netlify.
3. Seret (drag and drop) folder Portfolio_Randhan yang berisi index.html, style.css, dan script.js ke area upload.
4. Tunggu proses selesai. Netlify akan memberikan alamat website.
5. Buka alamat tersebut untuk memastikan website tampil dengan benar.
6. Salin alamat website dan tempelkan ke kolom "Link Hosting" pada formulir dosen.

CATATAN
- Link hosting harus berupa alamat website yang sudah berhasil dipublikasikan.
- Upload file ZIP Portfolio_Randhan.zip ke kolom "File Project (rar / zip)".
- Batas ukuran pada formulir dosen adalah 10 MB.
